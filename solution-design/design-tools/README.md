# Design document tools

`solution-design.md` is the single proposal. Its HTML and PDF present three views, one per A4 landscape page: AWS infrastructure, backend components and frontend design. The opening explains the problem and design approach. The backend page pairs recommendation inputs with quality targets; the frontend page has one browser technology table. There is no separate security, testing or improvement section.

Run these commands from the extracted `solution-design/` folder. Install the document dependencies:

```bash
python3 -m pip install -r design-tools/requirements.txt
npm ci --prefix design-tools
```

Each current view has editable Excalidraw source plus SVG and PNG exports. Regenerate them with:

```bash
python3 design-tools/presentation_views.py
DESIGN_CHROMIUM_PATH=/path/to/chromium node design-tools/render-views.mjs aws-overview solution-components frontend-design
```

The generator replaces those scenes and SVGs, including direct visual edits. Edit the generator first when maintaining their layouts. For a scene edited directly in Excalidraw, export its SVG using the same filename instead, then regenerate its PNG.

Render the browser document and export the proposal:

```bash
python3 design-tools/render-design.py
DESIGN_CHROMIUM_PATH=/path/to/chromium node design-tools/export-pdf.mjs
```

Rendering uses local assets and PDF export blocks browser network access. The print layout uses 10-point body text, 9.5-point tables and technology entries, and 15/13/10.5-point headings. Diagram fonts are also reduced: AWS service names use 34 source pixels, descriptions 29 and the smallest labels 28. Backend and frontend component text uses 28 source pixels, with some dependency labels at 27. Recheck the actual PDF page count and diagram readability after content changes. The approved version has three pages in total.

The AWS canvas is 2400 by 1020; the backend is 2200 by 850 and the frontend is 2200 by 1000. The taller component views use more space between rows, connectors and shared information. This places the supporting text lower on pages 2 and 3 without changing its wording or font sizes. API Gateway sits next to the browser, inside the regional boundary. Bedrock sits above and to the right of the refresh Lambda, leaving a straight connection to the external feeds.

Headings and component names use Space Grotesk; body text and labels use Inter. The licensed WOFF2 files in `fonts/` are embedded in the HTML and SVG exports, so PNG and PDF rendering work offline. Native Excalidraw text uses its built-in Helvetica font; the generator applies the presentation fonts to exported views. Both font licences are included in that folder.

The frontend and backend views use UML component rectangles with component icons and dashed, open-arrow usage dependencies. The AWS view uses deployment nodes, a grouped scheduling node and labelled global, regional, user-device and external boundaries. It shows browser connections to CloudFront, Cognito and API Gateway; frontend internals remain in their own view. Monitoring is a shared strip rather than individual function connections. Legends explain the symbols and colours used.

The dashed API Gateway-to-Cognito dependency identifies the configured token authorizer. It represents configuration, not an extra application call for every request. AWS CDK is expanded to Cloud Development Kit beside its infrastructure-as-code role. The regional boundary omits the region identifier.

The renderer displays the infrastructure technology table as six choices in three columns. The backend page pairs its two detail sections; the frontend page uses a single technology table. Source text and choices remain in Markdown; the renderer controls presentation and never inserts design claims.

Earlier supporting documents and other diagrams remain as references. The combined view is generated by `build-architecture.py`. The earlier `build-views.py` builder delegates AWS and backend generation to `presentation_views.py`, so it does not restore their superseded layouts. Document export leaves all diagram sources unchanged.
