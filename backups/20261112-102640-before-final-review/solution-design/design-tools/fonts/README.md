# Presentation fonts

Inter is used for body text and labels. Space Grotesk is used for headings and component names. These Latin WOFF2 files come from the Fontsource distributions for Inter and Space Grotesk.

Both families use the SIL Open Font License. The licence texts are included as `inter-LICENSE` and `space-grotesk-LICENSE`.

`diagram.py` embeds the files directly into SVG and HTML assets. Rendering requires no font download. Native Excalidraw text uses the editor's built-in Helvetica font.
